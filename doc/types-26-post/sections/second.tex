\section{Second-Order}
\label{sec:second}

In this section, we begin by examining the nested datatype
\AgdaDatatype{Bush} as a motivating example, and work out its semantics by
constructing an explicit container representation. We then generalize this
example to an arbitrary second-order setting, introducing second-order
containers and second-order W-types (and M-types).

\paragraph*{Second-Order W-type}

Does every second-order container have an initial algebra? We answer this
question positively by constructing \emph{second-order W-types}. Given a
second-order container \AgdaBound{H} and an \AgdaBound{H}-algebra
\AgdaSymbol{(}\AgdaBound{F}\AgdaSymbol{,}\AgdaBound{α}\AgdaSymbol{)}, we require
a unique \AgdaFunction{fold2W} making the following diagram commute:

\begin{tikzcd}[column sep=8em, row sep=large]
  \AgdaFunction{app}\;\AgdaBound{H}\;(\AgdaFunction{2W}\;\AgdaBound{H})
    \arrow[r, "{\AgdaFunction{app₁}\;\AgdaBound{H}\;(\AgdaFunction{fold2W}\;\AgdaBound{α})}"]
    \arrow[d, "{\AgdaFunction{2sup}}"'] &
  \AgdaFunction{app₁}\;\AgdaBound{H}\;\AgdaBound{F}
    \arrow[d, "{\AgdaBound{α}}"] \\
  \AgdaFunction{2W}\;\AgdaBound{H}
    \arrow[r, dashed, "{\AgdaFunction{fold2W}\;\AgdaBound{α}}"'] &
  \AgdaBound{F}
\end{tikzcd}

We first construct \AgdaFunction{2W}, which must be a fixed point of \AgdaFunction{app}\AgdaSpace{}\AgdaBound{H}:

\[ \AgdaFunction{2W}\;\AgdaBound{H}\;\AgdaFunction{≃}\;\AgdaFunction{app}\;\AgdaBound{H}\;(\AgdaFunction{2W}\;\AgdaBound{H}) \]

Splitting this explicitly into shapes and positions yields:

\[ \AgdaDatatype{2WS}\;\AgdaBound{H}\;\AgdaOperator{\AgdaInductiveConstructor{◃}}\;\AgdaDatatype{2WP}\;\AgdaBound{H}\;\AgdaFunction{≃}\;\AgdaFunction{appS}\;\AgdaBound{H}\;(\AgdaFunction{2W}\;\AgdaBound{H})\;\AgdaOperator{\AgdaInductiveConstructor{◃}}\;\AgdaFunction{appP}\;\AgdaBound{H}\;(\AgdaFunction{2W}\;\AgdaBound{H}) \]

Following the \AgdaDatatype{Bush} example, we again attempt a definition by
induction-induction:

\input{code/bad2w}

However, Agda rejects both \AgdaDatatype{2WS} and \AgdaDatatype{2WP} as not
strictly positive, even though they are morally strictly positive. This is
because \AgdaFunction{appS} and \AgdaFunction{appP} are defined by recursion,
and Agda cannot unfold such recursive definitions when checking strict
positivity. Our solution is to generalize the original equation to:

\AgdaFunction{2W-d}\;\AgdaBound{H'}\;\AgdaBound{H}\;\AgdaFunction{≃}\;\AgdaFunction{app}\;\AgdaBound{H'}\;(\AgdaFunction{2W-d}\;\AgdaBound{H'}\;\AgdaBound{H})

Splitting again into shapes and positions:

\AgdaRecord{2WS-d}\;\AgdaBound{H'}\;\AgdaBound{H}\;\AgdaOperator{\AgdaInductiveConstructor{◃}}\;\AgdaDatatype{2WP-d}\;\AgdaBound{H'}\;\AgdaBound{H}\;\AgdaFunction{≃}\;\AgdaFunction{appS}\;\AgdaBound{H'}\;(\AgdaFunction{2W-d}\;\AgdaBound{H'}\;\AgdaBound{H})\;\AgdaOperator{\AgdaInductiveConstructor{◃}}\;\AgdaFunction{appP}\;\AgdaBound{H'}\;(\AgdaFunction{2W-d}\;\AgdaBound{H'}\;\AgdaBound{H})

This equation can now be turned into a well-typed definition by
induction-induction:

\input{code/2w-d}

This diagonalization trick works for the following reason. On shapes, the
inductive definition of \AgdaRecord{2WS-d} internalizes the recursive
definition of \AgdaFunction{appS} by performing induction over \AgdaBound{H'}.
We must keep a separate copy of \AgdaBound{H}, since \AgdaFunction{2W}\;
\AgdaBound{H}, which is the special case \AgdaFunction{2W-d}\;\AgdaBound{H}\;
\AgdaBound{H}, must remain fixed throughout the induction. This approach
eliminates the explicit use of \AgdaFunction{appS}, so the definition passes the
strict positivity check while remaining correct. The same reasoning applies to
positions.

Finally, \AgdaFunction{2W} is recovered by instantiating both arguments to
\AgdaBound{H} and recombining the shape and position parts:
\AgdaFunction{2W}\;\AgdaBound{H}\;\AgdaSymbol{=}\;\AgdaDatatype{2WS-d}\;\AgdaBound{H}\;\AgdaBound{H}\;\AgdaOperator{\AgdaInductiveConstructor{◃}}\;\AgdaDatatype{2WP-d}\;\AgdaBound{H}\;\AgdaBound{H}

It remains to construct many other components of the diagram. Concretely,
we define \AgdaFunction{2sup}, the algebra structure on \AgdaFunction{2W};
\AgdaFunction{fold2W}, the second-order folding function;
\AgdaFunction{commute2W}, which shows that the diagram commutes;
and \AgdaFunction{uniquefold2W}, which proves the uniqueness of the fold.

Dually, we define the type \AgdaFunction{2M} by coinduction-induction and prove
that it is the terminal coalgebra in the second-order setting. The construction
is almost identical, except that corecursive definitions must be guarded. We
omit these proofs from the paper.
