\section{Basics}
\label{sec:basics}

In this section, we review the categorical semantics of simple inductive types by means of a worked example, and then generalize it to containers and W-types. Finally, we introduce the category of containers.

\paragraph*{Semantics of Types}

Intuitively, a container morphism encodes a polymorphic function between the corresponding functors. For example, we define \AgdaFunction{head}\;\AgdaSymbol{:}\;\AgdaSymbol{(}\AgdaBound{X}\;\AgdaSymbol{:}\;\AgdaPrimitive{Type}\AgdaSymbol{)}\;\AgdaSymbol{→}\;\AgdaDatatype{List}\;\AgdaBound{X}\;\AgdaSymbol{→}\;\AgdaDatatype{Maybe}\;\AgdaBound{X} to be the total function that returns the first elements from a \AgdaDatatype{List}. Its corresponding container morphism representation \AgdaFunction{headᶜ}\;\AgdaSymbol{:}\;\AgdaDatatype{ℕ}\;\AgdaOperator{\AgdaInductiveConstructor{◃}}\;\AgdaDatatype{Fin}\;\AgdaOperator{\AgdaRecord{→ᶜ}}\;\AgdaDatatype{Bool}\;\AgdaOperator{\AgdaInductiveConstructor{◃}}\;\AgdaDatatype{isTrue}, is described by a map on shapes together with, for each shape, a map on positions. The map on shapes sends \AgdaInductiveConstructor{zero} (empty list) to \AgdaInductiveConstructor{false} (error state); and sends every \AgdaInductiveConstructor{suc}\;\AgdaBound{n} (non-empty list) to \AgdaInductiveConstructor{true} (result state). The map on positions goes in the opposite direction: for each position in the output, it specifies the position in the input from which the data is taken. The empty list case has no output positions, so there is nothing to define. In the non-empty case the single position (result) comes from the  \AgdaInductiveConstructor{fzero}\;\AgdaSymbol{:}\;\AgdaDatatype{Fin}\;\AgdaSymbol{(}\AgdaInductiveConstructor{suc}\;\AgdaBound{n}\AgdaSymbol{)} (the position of the first element of the list).

Categorically, container morphisms correspond to natural transformations between the associated functors. We define identities \AgdaFunction{idᶜ} and composition \AgdaFunction{\_∘ᶜ\_}, and verify the identity and associativity laws, and hence show that containers and their morphisms form a category.
