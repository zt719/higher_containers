\section{Settings}
\label{sec:settings}

Our metatheory is HoTT~\cite{HoTTBook}, and we formalize this work in Cubical Agda~\cite{Norell07,VezzosiMA19}. The equality \AgdaBound{x}\;\AgdaFunction{≡}\;\AgdaBound{y} is given by the primitive path type \AgdaPrimitive{Path}: a path is a function from an abstract interval whose endpoints are \AgdaBound{x} and \AgdaBound{y}. One benefit of path is that function extensionality \AgdaFunction{funExt} is derivable and computes: two functions are equal if they agree on every input, rather than being definitionally equal. Cubical Agda also supports heterogeneous equality primitively through \AgdaPrimitive{PathP}.

We do not assume axiom K (uniqueness of identity proofs), and reason about equality only through the J-rule (path induction). We write \AgdaPrimitive{Type} for the universe of types, whose elements are \emph{not} assumed to be homotopy sets \AgdaFunction{hSet}. At the same time, the types we study do not rely on any higher path structure. Accordingly, the categories considered in this paper are \emph{wild categories}: the morphisms between two objects form a type rather than set, which means that the unit and associativity laws hold up to paths.
